🚀 TechStore – E-commerce Workshop

TechStore es un proyecto académico desarrollado como parte del taller de
Diseño y Creación de Páginas Web para Negocios Digitales.
Consiste en una aplicación web tipo e-commerce básica, desarrollada con Node.js,
que permite mostrar y filtrar productos mediante rutas dinámicas.

🛠️ Tecnologías Utilizadas
- Backend: Node.js y Express
- Frontend: EJS (Embedded JavaScript Templates)
- Diseño: Bootstrap 5
- Herramientas de desarrollo: Nodemon
- Control de versiones: Git y GitHub

🌟 Características Actuales
- Navegación dinámica mediante rutas configuradas para filtrar productos por categorías
  como Computadores y Periféricos.
- Renderizado de información dinámica desde el servidor utilizando el motor de plantillas EJS.
- Interfaz responsiva y sencilla implementada con Bootstrap.

📂 Estructura del Proyecto
.
├── app.js           # Archivo principal del servidor y configuración de rutas
├── package.json     # Gestión de dependencias y scripts
├── public/          # Archivos estáticos (CSS, imágenes, JavaScript del cliente)
└── views/           # Plantillas de la interfaz
    └── index.ejs    # Vista principal de productos

▶️ Ejecución del Proyecto
1. Clonar el repositorio desde GitHub
2. Instalar las dependencias:
   npm install
3. Ejecutar el servidor en modo desarrollo:
   npm run dev
4. Abrir en el navegador:
   http://localhost:3000
